## ✨ ¿Por qué Thwip Shot?

Thwip Shot fue creado para resolver la lentitud y limitaciones de la herramienta de recortes tradicional de Windows, ofreciendo un flujo de trabajo instantáneo, intuitivo y estéticamente impecable.

### ⚡ Características Principales

* 🧊 **Congelado de Pantalla Instantáneo:** Al presionar `Ctrl + Shift + S`, la pantalla se congela en milisegundos sin parpadeos, glitches ni retrasos.
* 🔍 **Lupa de Precisión 4x:** Visualiza píxel por píxel con coordenadas exactas y selector de color hexadecimal en tiempo real.
* 📋 **Copia Directa al Portapapeles:** Pega tus capturas al instante con `Ctrl + V` en Discord, WhatsApp, Telegram, Photoshop, Slack o donde quieras.
* 🎨 **Editor de Anotaciones Rápido:**
  * Flechas inteligentes y líneas rectas.
  * Formas geométricas (rectángulos redondeados, elipses).
  * Marcador / Resaltador translúcido.
  * Censurador / Pixelador en tiempo real para proteger contraseñas y datos sensibles.
  * Texto interactivo con contraste dinámico.
  * Pincel suave y borrador inteligente.
* 🔄 **Actualizaciones Automáticas y Silenciosas:** Siempre al día mediante GitHub Releases sin molestos asistentes de instalación.
* 🌙 **Diseño Dark Cosmic:** Interfaz moderna, con esquinas redondeadas, efectos de cristal y paleta oscura de alto contraste.

## ⌨️ Atajos de Teclado Útiles

| Atajo | Acción |
| :--- | :--- |
| `Ctrl + Shift + S` | Iniciar captura de región desde cualquier lugar (global) |
| `N` (en el editor) | Tomar una **Nueva** captura (el editor se oculta automáticamente) |
| `Ctrl + C` | Copiar imagen editada al portapapeles |
| `Ctrl + S` | Guardar archivo en disco |
| `Ctrl + Z` / `Ctrl + Y` | Deshacer / Rehacer cambios |
| `Esc` | Cancelar selección / Cerrar overlay |

## 📥 Instalación

1. Descarga el instalador oficial desde [GitHub Releases](https://github.com/zakyline/thwip/releases/latest/download/Thwip-Shot-Setup.exe).
2. Ejecuta `Thwip-Shot-Setup.exe`.
3. ¡Listo! La app se iniciará minimizada en la bandeja del sistema y estará lista para capturar con `Ctrl + Shift + S`.
