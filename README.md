## Características

* **Captura inmediata (`Ctrl + Shift + S`):** Congela la pantalla al instante sin lag ni parpadeos.
* **Lupa de precisión (4x):** Visualización píxel por píxel con lector de color HEX.
* **Copia directa:** Pega (`Ctrl + V`) directamente en Discord, WhatsApp, Slack, Photoshop, etc.
* **Herramientas de edición:** Flechas, formas, texto, resaltador y pixelador para censurar datos sensibles.
* **Actualizaciones automáticas:** Se mantiene al día en segundo plano mediante GitHub Releases.
* **Interfaz oscura:** Diseño limpio, moderno y con soporte para modo oscuro.

---

## Atajos útiles

| Atajo | Acción |
| :--- | :--- |
| `Ctrl + Shift + S` | Iniciar captura |
| `N` | Nueva captura (desde el editor) |
| `Ctrl + C` | Copiar al portapapeles |
| `Ctrl + S` | Guardar como archivo |
| `Ctrl + Z` / `Ctrl + Y` | Deshacer / Rehacer |
| `Esc` | Cancelar o cerrar |

## Instalación

1. Descarga el instalador: [Thwip-Shot-Setup.exe](https://github.com/zakyline/thwip/releases/latest/download/Thwip-Shot-Setup.exe).

3. La aplicación se abrirá en la bandeja del sistema lista para usarse.
