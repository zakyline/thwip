## Descripción

Thwip Shot es una utilidad diseñada para optimizar los flujos de trabajo de captura y anotación en Windows, eliminando la latencia y la fricción asociadas a la herramienta nativa del sistema.

### Características

* **Captura instantánea:** Al accionar el atajo global `Ctrl + Shift + S`, el marco de pantalla se congela de forma inmediata sin parpadeos de renderizado ni demoras.
* **Lupa de inspección 4x:** Facilita la selección píxel por píxel, integrando coordenadas cartesianas en pantalla y un selector de color en formato hexadecimal.
* **Integración con el portapapeles:** Exportación directa a la memoria (`Ctrl + V`) compatible con aplicaciones de mensajería, suites de productividad y software de diseño.
* **Herramientas de anotación:**
  * Vectores direccionales, flechas estructuradas y líneas ortogonales.
  * Geometría predefinida (rectángulos con radio de curvatura y elipses).
  * Pincel de resaltado translúcido de baja saturación.
  * Módulo de censura mediante pixelado dinámico para enmascarar datos sensibles.
  * Tipografía interactiva con ajuste automático de contraste.
  * Trazado libre y borrador segmental.
* **Actualizaciones silenciosas:** Sincronización continua de versiones a través de GitHub Releases sin interrumpir la experiencia de uso.
* **Interfaz Cosmic Dark:** Esquema visual oscuro de alto contraste, esquinas redondeadas y efectos de desenfoque acrílico adaptados al lenguaje visual de Windows 11.

## Atajos de teclado

| Combinación | Función |
| :--- | :--- |
| `Ctrl + Shift + S` | Disparador global de captura por región |
| `N` *(en editor)* | Iniciar una nueva captura (oculta el editor actual) |
| `Ctrl + C` | Copiar la selección o edición al portapapeles |
| `Ctrl + S` | Guardar el resultado en disco local |
| `Ctrl + Z` / `Ctrl + Y` | Deshacer / Rehacer la última acción |
| `Esc` | Cancelar selección activa o cerrar la interfaz superpuesta |
